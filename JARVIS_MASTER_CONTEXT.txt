  - Padded Vocabulary Dimension: 50,304 (padded to multiple of 64/128 for tensor core alignment)
  - Max Sequence Length: 512 (can scale to arbitrary N via linear attention state carry)

Mathematical Formulations:
1. Infinite Associative Attention (Eq. 1-2):
     S_t = gamma * S_{t-1} + V_t (x) K_t^T
     Z_t = S_t * Q_t
   where gamma = sigmoid(gamma_raw) is a learnable per-head recurrent decay scalar.
   Vectorized via 64-token intra-chunk decayed attention and cross-chunk state accumulation.
   Q and K pass through ELU+1 feature maps for numerical stability.

2. Spiking Ternary Weight Quantization Q1.58 (Eq. 3-4):
     alpha = mean(|W|)
     W_ternary = clamp(round(W / (alpha + 1e-8)), -1, 1)
     W_quant = W_ternary * alpha
   During backprop, Straight-Through Estimator (STE) is applied (Eq. 5):
     grad_W_FP32 = grad_W_quant * 1{|W_FP32| <= 1.0}

3. Sparse Mixture-of-Experts (Eq. 6, Algo 1):
   - Router logits: logits = X * W_router + N(0, sigma^2) (Gaussian exploration noise before top-k)
   - Gate weights: softmax over top-2 selected indices.
   - Load-balancing auxiliary loss: L_balance = alpha_bal * E * sum_i (f_i * P_i)
     where f_i is fraction of tokens dispatched to expert i, and P_i is mean gating probability.

4. Liquid State Fusion (LSF) SNN Dynamics (Eq. 8, Algo 1 L15):
   - Continuous-time Leaky Integrate-and-Fire (LIF) membrane ODE discretised to EMA:
     alpha_dyn = alpha_min + (alpha_max - alpha_min) * sigmoid(-var_scale * Var(Expert_Out))
     H_t = alpha_dyn * H_{t-1} + (1.0 - alpha_dyn) * M_t
   - Membrane state H persists across sequence processing.

5. Reflective Regularization (Eq. 7):
   - L_reflect = lambda_ref * [(mu_batch - mu_target)^2 + max(0, Var(act) - tau_max)]
   - Stabilizes spiking dynamics against explosion or quiescence.

6. EXP-27-001: Vectorize `moe_scatter_combine_add_residual` (int4)

     to execute 8 dependent transcendental chains serially, destroying ILP and stalling execution units.
   - Lesson: Vectorization is severely harmful for compute-bound kernels with serial transcendental math chains.

  - Acceptable on SM120; single float atomic contention is minor.

  - Code smell, but compiler resolves unrolled constants into registers correctly.

BUG-008: `fused_rmsnorm_bwd_kernel` passes `grad_weight` but never writes it (cuda_engine_kernels.cu:301-307).
  - RMSNorm weights do not accumulate gradients in that kernel.

  - Phase 1 writes `row_add`, Phase 2 re-reads it. Register caching could eliminate 192 MB/step DRAM traffic.
BUG-010: `fused_elu_rope_prep_kernel` is scalar (attention.cu:16-27). Minor bandwidth opportunity.
BUG-011: `fused_rope_kernel` has 32 threads/block (1 warp) giving low SM occupancy (attention.cu:98-100).
BUG-012: `fused_add_residual_kernel` is scalar (not on hot path).
BUG-013: No `--ptxas-options=-v` in `setup.py` build flags; hides register counts and occupancy.
BUG-014: AdamW uses `sqrtf(v) + eps` instead of `rsqrtf` (optimizer.cu:275).

13. CORE TERMINOLOGY & GLOSSARY
====================================================================================================
[VERIFIED]
- **Associative Linear Attention**: O(N) linear-time attention replacing softmax quadratic attention
  with recurrent outer-product state accumulation: S_t = gamma * S_{t-1} + V_t (x) K_t^T.
- **BitNet b1.58 / Q1.58**: Quantization scheme restricting model weights to ternary values {-1, 0, +1}
  scaled by a per-tensor AbsMean scalar alpha.
- **STE (Straight-Through Estimator)**: Backpropagation technique for non-differentiable quantization
  where gradients pass through unchanged within clipping boundaries (|w| <= 1.0).
- **LSF (Liquid State Fusion)**: Continuous-time SNN membrane potential model discretised to dynamic
  exponential moving average (EMA) based on expert activation variance.
- **Top-2 MoE**: Sparse Mixture of Experts routing where exactly 2 of 4 experts are selected per token.
- **CUDA Graph Replay**: Recording an entire sequence of CUDA kernel launches into an execution graph
  that can be replayed by the GPU hardware with zero CPU launch overhead.
- **L2 Cache Pinning**: Structuring intermediate activation buffers so they remain resident inside the
  48 MB on-chip L2 cache, avoiding roundtrips to external GDDR7 DRAM.
- **Vec8 / 128-bit Vectorization**: Loading or storing 8 consecutive BF16 elements (16 bytes = 128 bits)
  in a single GPU memory instruction (`LDG.128` / `STG.128` via `uint4` or `float4`).
- **TMA (Tensor Memory Accelerator)**: Hardware block in modern NVIDIA GPUs (Blackwell SM120) for
  asynchronous, multidimensional tensor transfers between global memory and shared memory.
- **Zero-Grad Overwrite**: Setting cuBLASLt `beta = 0.0f` on the first microstep of gradient accumulation
  so the GEMM directly overwrites memory, eliminating the need for a separate zero-gradient write pass.
